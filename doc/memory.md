# Memory — doc

## Rôle du dossier

Notebooks, figures et jeux de données de démonstration associés à D²IC.

## Fichiers importants

- `00_Validation.ipynb` : validation interactive.
- `01_Simple2D_DIC.ipynb` : introduction à un calcul DIC 2D.
- `11_Advanced_Use_Uncertainty_Propagation.ipynb` : propagation d’incertitude par différentiation JAX.
- `img/` : petites séquences de référence utilisées par les exemples et tests.

## Concepts physiques ou numériques

Les notebooks illustrent l’identification de déplacement, les déformations et la propagation d’incertitude.

## Conventions

Les scripts exécutables de validation résident dans `examples/`; `doc/` contient la documentation interactive et ses données.

## Points d’attention

Les sorties de notebooks sous `doc/_outputs` sont générées et ignorées par Git.
